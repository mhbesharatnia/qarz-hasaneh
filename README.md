# صندوق قرض‌الحسنه

پروتوتایپ تک‌صفحه‌ای برای ثبت وام قرض‌الحسنه، مدارک، اقساط، واریزها و نامه تسویه.

**https://mhbesharatnia.github.io/qarz-hasaneh/**

## کار مشترک روی یک صندوق

باکت آروان را **خصوصی** بگذارید. اپ لینک عمومی نمی‌سازد؛ خواندن و نوشتن فقط با درخواست امضاشده است.

1. در «اتصال مشترک» Endpoint، باکت، Access Key و Secret Key را بگذارید و ذخیره کنید.
2. «خروجی اتصال برای همکار» را بگیرید (`qarz-arvan-share.json`).
3. همان فایل را به همکارتان بدهید تا با «ورود فایل اتصال» وصل شود.
4. هر دو به یک باکت وصل می‌شوید؛ پرونده‌ها و مدارک مشترک می‌شود و حدود هر ۱۲ ثانیه تغییرات طرف مقابل می‌آید. دکمه «بروزرسانی» هم فوری می‌کشد.

در CORS باکت، origin صفحه (`https://mhbesharatnia.github.io`) را با متدهای **GET** و **PUT** و هدر `*` مجاز کنید. باکت را public نکنید.

فایل اتصال شامل کلید است؛ فقط به کسی بدهید که باید به صندوق دسترسی داشته باشد.
