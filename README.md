# صندوق قرض‌الحسنه

پروتوتایپ تک‌صفحه‌ای برای ثبت وام قرض‌الحسنه، مدارک، اقساط، واریزها و نامه تسویه. همهٔ داده‌ها در مرورگر شما (`localStorage`) ذخیره می‌شود و سروری لازم نیست.

## اجرای زنده

پس از فعال شدن GitHub Pages:

**https://mhbesharatnia.github.io/qarz-hasaneh/**

فایل را می‌توانید محلی هم باز کنید؛ برای خروجی اکسل بهتر است با یک سرور ساده سرو شود:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## امکانات

- ثبت مشخصات کامل **دریافت‌کننده**، **معرف** و **ضامن**
- اسکن مدارک هر سه نفر (مدارک معرف اختیاری)
- نامه معرف، نامه تایید ضامن، و تایید دریافت **چک ضمانت** یا **سفته ضمانت**
- همهٔ تاریخ‌ها با **تقویم شمسی** انتخاب می‌شوند (تولد، سررسید، واریز)
- درصد **کارمزد** با پیش‌فرض صفر
- اتصال به **فضای ابری آروان**: فایل مدارک و بکاپ خودکار در باکت شما ذخیره می‌شود (دکمه «آروان» در بالای صفحه)
- خروجی **Excel** از جدول اقساط
- هشدار پس از **۵ روز** تأخیر: چند روز از سررسید قسط آقا/خانم گذشته و نمایش شماره تلفن‌ها
- ثبت هر واریز: مبلغ، زمان، روش، کد رهگیری، عکس رسید و توضیح
- پس از تسویه کامل: **نامه تایید تسویه** و اعلام به مدیر حسابداری برای عودت چک/سفته

## پشتیبان‌گیری

از دکمه‌های «خروجی پشتیبان» و «بازیابی» در بالای صفحه استفاده کنید. اسکن مدارک داخل همان فایل JSON ذخیره می‌شود؛ اگر حجم مدارک زیاد باشد ممکن است محدودیت حافظه مرورگر پیش بیاید.
